日期：2026-11-12。契约：[最终控制台菜单](final-console-menu.md#221-主线联动补全)。源码位置：tinybot-server/web。

## 实现范围

模型服务 → 默认模型 → 当前智能体草稿 → 调试 → 发布快照 → 绑定设备。只使用当前会话的前端数据，没有调用模型、MCP、搜索、沙箱执行或设备服务。主题、品牌和机器人形象的存储键及序列化方式不变，未清空、迁移或覆盖已有浏览器配置。

1. 模型请求本地模拟完成后，用户主动选择“用于本地演练”，连接登记为“演示可用”；编辑连接仍重新回到待检测。
2. 新建对象使用显式默认模型；已有对象仅通过“采用默认模型”修改草稿。新增 VAD、意图、外部记忆默认槽位。
3. 草稿可以从智能体列表、独立调试和人物面板进入调试。正常完成轮次才登记资格，临时覆盖、停止及依赖变化不能授权旧配置发布。
4. 本轮配置清单包含模型及能力连接、知识库模型依赖、知识文档、沙箱、授权工具、技能正文、当前智能体生效记忆和历史上下文。工具清单不包含凭据。
5. 知识库嵌入、记忆提取/召回、工具模型、TTS 模型及音色兼容性均参与校验。依赖变化使旧资格失效；普通记忆条目变化不强制重新发布。
6. 发布形成快照，设备调试使用快照。新增绑定仅形成待接入记录，不改变真实设备状态；未发布草稿不会替换设备版本。
7. 长期记忆表单不再把未保存的默认候选显示成已选模型。新启用时填入实际引用，编辑已有策略保留明确选择。
