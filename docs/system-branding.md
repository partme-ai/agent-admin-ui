# 系统标识编辑约定

日期：2026-11-12。沿用 Console 的系统基础信息功能，不新增规格体系。

- 入口：系统 → 基础信息 → 系统信息 → 编辑标识，使用紧凑抽屉。
- 可编辑系统名称（1～24字）、Slogan（1～48字）及 Logo（PNG/JPEG/WebP，256 KiB 以内、4096×4096 以内）。默认 TinyBot / 机器人控制中心 / 原机器人图标。
- 抽屉草稿实时预览，保存成功才更新侧栏、手机顶部、导航抽屉标题、页面标题和系统信息。取消不写入；恢复默认只更新抽屉草稿，仍需保存。
- 本地独立存储 tinybot.system-brand.v1，schema_version=1；不改主题、机器人形象及业务配置，不把本地保存描述为服务端全局配置。
- 图片只允许受控 data URL，不接受远程 URL、SVG 或任意 HTML；检查格式、签名、体积及浏览器实际解码。保存失败保留当前值和草稿，损坏存储回退默认显示但不覆写原记录；图片加载失败回退原图标。
- 支持同源其他窗口的标识配置变更；旧浏览器无此键时保持当前默认外观。长名称/口号在固定外壳内省略，不改变侧栏尺寸。
- 验收：三端编辑/取消/保存/刷新/默认恢复、上传/移除、损坏文件和超限校验、跨窗口同步、存储失败与独立键保护；前端回归、类型检查、构建。无真实服务或原生能力接入。
