# TinyBot-Web 最终菜单与交互基线

2026-11-12，以本轮用户菜单为增量事实源。沿用 React + antd、既有流式布局与 16px 外边距；不改 Rust 业务、不安装运行环境、不请求真实模型或解析服务。主题、机器人形象持久化键和旧路由继续兼容。

主菜单顺序：工作台 → 设备(Bot) → 模型 → 知识库 → 智能体 → 资源 → 系统。

- 设备：设备广场、我的设备、固件更新、数据与统计。设备详情保留智能体、知识、形象、参数、对话、状态、日志及设备统计。
- 模型：模型服务；本地模型（运行环境、模型列表）；模型网关（模型 API、默认模型、负载、降级、限流、熔断）；数据与统计。
- 知识库：公共知识库、知识库管理、共享空间、MCP 服务。创建、编辑、上传、图谱由知识库详情承接，不增加空的顶层菜单。
- 智能体：市场、插件、连接、技能、沙箱、工具、我的智能体、智能体调试、数据与统计。工具包括电脑操控、浏览器、网页搜索、网页抓取、文档处理、OCR。记忆及沙箱、工具授权属于具体智能体配置；调试产物带智能体和会话归属。
- 资源：基础信息、资源空间、存储引擎。一个类型可创建多个具名实例，知识库引用稳定实例 ID；已有文件的存储绑定不改写。
- 系统：基础信息、系统主题、系统角色、系统用户、安全审计、系统设置。CLI 保留旧链接，退出主菜单。
- Web 头像：基础信息、界面语言、系统主题、颜色主题、界面缩放、注销登录。删除界面模式入口，保留旧偏好数据。

## 可观察验收

1. 三端菜单来自同一数据源；所有叶子能定位页面；折叠弹出与展开菜单图标一致。
2. 本地运行目标是 Server/Desktop 主机，不把浏览器或手机当作推理宿主。前端演示主机可切换。模型检查不足时禁止模拟安装；有资源压力时二次确认；取消后可重试；任务状态明确标为模拟。
3. 沙箱有执行目标、隔离方式、网络、超时与目录约束；工具按适配器分别配置。智能体只能选择已配置的资源，调试与发布检查相同依赖，修改资源使原调试结果失效。
4. 产物由调试记录保存为真实可下载的文本文件，保留智能体/会话归属；不伪造模型生成文件。
5. 存储实例新增、编辑、停用检查与知识库引用联动；不删除使用中的实例。
6. Desktop 1280×1024、Tablet 768×1024、Mobile 390×884 检查导航、表单、确认、取消和底部按钮，不据此声称原生或真实服务验收。

## 参考及支持边界

- Cherry Studio：沿用已有文档/OCR适配目录及厂商表单，接入配置集中维护。知识库和智能体其他位置仅选择已配置模型。
- DeepSeek 官方 Search/Fetch：<https://api-docs.deepseek.com/zh-cn/guides/search/>；抓取返回 Markdown，搜索和抓取分别配置，不混成 LLM。
- vLLM：<https://docs.vllm.ai/en/stable/getting_started/installation/>；当前示例采用 Linux GPU 配置，其他官方后端须按版本另行核验。
- Ollama：<https://ollama.com/download>。运行环境覆盖 macOS/Linux/Windows，模型显存、内存仍需逐模型实测。

当前本地模型卡片的内存/磁盘/显存数字是明确标注的部署演示预算，不是官方最低硬件承诺。Web/手机/Pad只管理所连接主机；Tauri 插件随应用编译，动态业务配置及远程工具维持原有两层方案。实体设备支持、软件安装、资源检测、网络抓取、沙箱脚本运行与生成模型均待后端接入后验收。

## 2.21 主线联动补全

沿用本文件作为前端增量契约；不接入真实服务，不初始化新的规格体系。

- 模型服务保存后仍为待检测。用户完成本地请求模拟，再主动选择“用于本地演练”，才登记为演示可用；任何编辑重新回到待检测。这不代表真实连通性或模型能力通过验证。
- 默认模型补齐 VAD、意图和外部记忆服务。新建智能体显式默认值优先于工作空间基线；既有智能体不回写，只能主动“采用默认模型”进入草稿。已发布快照、知识、记忆记录和形象保持独立。
- 独立调试可选择未发布智能体，使用当前保存草稿。人物面板调试先保存；设备调试使用已发布快照及设备覆盖。所有入口共享配置、资源校验及完成回执。
- 完成且未中断的轮次，只有配置与依赖仍一致才登记发布凭证；临时覆盖不会授权原配置发布。模型分类错误、记忆模型待检测、工具模型分类错误、依赖停用或变更均使旧凭证失效。
- 请求清单携带主模型、能力模型、限定知识文档、当前智能体生效记忆、已装配技能正文、沙箱配置与逐项授权工具。工具清单不携带凭据。执行过程展示本轮采用的实际本地内容。
- 发布形成快照；新增绑定设备保持“待接入”。未发布草稿不替换设备使用的版本。原生插件及本机工具仍遵守 Web、Desktop、Android Tablet、iPad 宿主边界。

验收：通过真实页面操作从新连接开始，完成默认模型、新智能体、知识/记忆/技能/沙箱/工具装配、调试、发布、绑定及设备调试；覆盖 1280×1024、768×1024、390×884。测试包含资源变更撤销资格、旧快照隔离、中断无凭证及无关记忆不撤销资格。浏览器证据见 [本轮验证记录](agent-delivery-verification.md)；本地模拟不作为真实服务或实体设备验收。
