# 共享空间创建与编辑

2026-11-12，前端会话增量。依据用户提供的 WeKnora 界面与菜单：知识库下收敛为公共知识库、知识库管理、共享空间。复用现有 React/antd、流式页面与独立会话数据，不初始化新的规格体系。

## 交互约定

- `/w/demo/knowledge/spaces` 为共享空间入口，新增 CON-P53，不改已有页面 ID 和链接。
- 列表支持全部、我创建的、我加入的，搜索与排序。默认空列表，不自动生成已共享数据。
- 创建/编辑共用同一个弹窗，包含基本信息、权限说明；Desktop/Tablet 左侧标签，Mobile 顶部标签。
- 名称必填、去掉首尾空白、最多 50 字；描述选填、最多 500 字。重复名称反馈在表单，不关闭弹窗。头像支持首字、图案与六种配色。
- 权限说明按管理员、编辑、只读展示五项能力，创建者成为管理员。只读矩阵不提供开关，不与系统角色权限混淆。前端检查不代替服务端授权。
- 创建保存后出现在列表；编辑回填原值，保存只改名称、描述、头像、更新时间，保留 ID、创建记录、成员及资源关联。
- 取消、关闭和离开保护未保存内容，继续编辑保留草稿，放弃不修改已保存值。保存缺项时回到基本信息页定位错误。
- 弹窗标题与底部操作左右 16px，正文可滚动，底部操作留在正文外；权限表格外层零内边距。

## 范围与兼容性

共享空间使用 `product.sharedSpaces`，与 OSS 资源空间 `product.spaces` 分离。不修改主题、系统标识、机器人形象存储，不自动改写知识库或智能体。沿用业务会话机制，刷新后新增空间会重置；不请求网络。

本次实现创建/更新界面、列表及只读权限说明。公共知识库仅统一入口名称，现有示例包逻辑保留；文档型/问答型完整改造不属于本次范围。

## 加入空间增量 · 2.11

- 列表和“我加入的”空状态提供加入入口。弹窗上方为输入邀请码、搜索共享空间两个标签，沿用当前主题与16px外框。
- 邀请码先查看空间预览，再确认加入。支持字母数字码及邀请链接中的 invite/code 参数；只解析码，不打开链接或发送请求。错误格式、不存在、过期、撤销分别反馈。
- 搜索只展示允许发现的本地示例空间，不枚举邀请专属空间；需要邀请码的空间不可从搜索直接加入，开放示例可预览后以只读身份加入。
- 预览展示名称、描述、成员数及加入后的角色；查看/取消不增加成员。角色来自邀请或开放规则，用户不能自行选择管理员。确认前重新检查邀请状态，重复加入不重复创建成员。
- 加入后进入“我加入的”列表。编辑/只读成员没有空间设置编辑入口，已有创建流程不变。
- 目录、邀请及加入结果都是明确标注的本地演练。有效示例码 TBDEMO01（只读）、TBEDIT02（编辑）；TBOLD003已过期，TBSTOP04已撤销。没有生成真实邀请、接入多人协作、成员管理、资源共享或服务端授权。

## 验收

三种浏览器视口 1280×1024、768×1024、390×884，逐项检查空列表、创建、必填、头像、权限切换、保存、编辑回填、重复名称、取消/继续编辑。核对无整页横向溢出、弹窗底部按钮可见，名称和描述可访问。

状态测试检查创建者权限、更新保留关联、越权拒绝、字段校验和菜单路由兼容。运行前端完整测试、类型检查、构建。实际证据另记于 `evidence/shared-spaces-2.10`。


## 2.14 创建后的空间管理

空间卡片可打开详情抽屉：共享知识库、共享智能体、成员、邀请、空间设置和权限说明。资源使用原始 ID 引用，撤销和解散只清理空间关联。管理员可管理本地成员、生成/撤销限期邀请码、配置搜索发现/加入审核/人数上限；添加、加入与审核均受人数限制，最后管理员受到保护。当前仍为单浏览器会话数据。
