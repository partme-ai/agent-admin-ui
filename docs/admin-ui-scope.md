# Agent Admin UI 通用管理界面

## Web / Desktop / Pad / Mobile 增量

Web、Desktop、Pad、Mobile 使用同一业务页面和本地配置，但有独立入口与不同的宿主导航。Web 保留完整管理侧栏；Desktop 与 Pad 的主导航聚焦工作区，在底部提供账户、终端互联和设置，设置打开独立导航；Mobile 使用底部导航与完整菜单抽屉。`compare.html` 以四个页签一次显示一端，可联动页面、子页面参数与主题，也可分别打开。原生设置的常规、外观、通知、语音和关于均有对应视图。入口地址和预览尺寸见中英文 README。根入口继续兼容旧书签，浏览器中的演示不代表已生成原生安装包。

本增量仅修改 `agent-admin-ui`，不改已有模型、知识、智能体和主题存储格式。静态预览可核对布局、导航和交互；真实服务与原生安装包仍需单独验证。

2026-11-12。本变更延续 docs/final-console-menu.md 的前端增量规格，不初始化新规格体系。当前需求优先于原 TinyBot 菜单；原说明保留作来源记录。

## 范围

主导航：工作台、模型、知识库、智能体、资源、系统。移除物理设备、绑定/配网/控制、OTA、设备统计、机器人屏幕与形象表情编辑。移除本地模型运行环境、安装与运行管理及 Ollama 专用配置。中央模型连接仍可连接用户自行提供的兼容 API，不安装推理环境。

智能体调试改为通用对话工作台，共用模型、知识、技能、MCP、沙箱、记忆与发布校验。停止或离开取消当前轮次，旧回应不得登记发布凭证；资源变化后重新调试。发布结束不要求绑定设备。通用 ASR/TTS、音色与文档音频解析配置保留。

默认名称 Agent Admin UI，Slogan 智能体管理控制台，Logo 使用应用网格。原默认 TinyBot 标识在读取时显示新默认；自定义名称、口号、上传 Logo 及原主题存储不覆盖、不清理。

## 验收

- 所有主导航、移动导航、搜索、预览页面均无已删除入口；旧设备与本地模型地址不再路由至旧页面。
- 首页、模板、智能体编辑、引导、权限、统计不再要求设备或显示机器人控制功能。
- 设备、本地模型安装、机器人形象专用页面及独占源模块从工程移除，共享颜色、主题、语音、模型连接继续可用。
- 从智能体选择模型与知识、装配技能/工具/沙箱/记忆、调试、发布的本地流程可执行。所有结果明确为模拟，不请求真实服务。
- Desktop 1280×1024、Tablet 768×1024、Mobile 390×884 实际页面核对导航、编辑、调试与发布。
- 原主题、自定义品牌和其他配置不被重置；仅修改 agent-admin-ui。
