# 模型集中配置与分类 · 2.16

按用户确认的边界，模型设置是接入、鉴权、地址、参数和分类的唯一维护位置。知识库、智能体及调试页面只选择模型，不再嵌套模型连接编辑器。没有可用连接时说明所缺类别，不以目录预设代替已配置模型，不修改已有连接、草稿和发布快照。

模型分类与厂商来源独立：LLM、SLM、VLLM、Embedding、Rerank、ASR、TTS、VAD、意图、记忆、RAG。模型设置提供分类筛选及已配置数量；按类别筛选厂商、连接和模型行。接入表单保存明确的用途分类；兼容语言协议可配置语言、轻量语言与视觉用途，视觉/轻量用途需由用户明确填写对应模型 ID，不因接口兼容就声明模型具备该能力。ASR、TTS、向量等继续使用各自专属协议与方案。

模型选择按连接 ID 关联和用途过滤，停用、缺失或类别不匹配的旧引用可见但不能作为新的有效选择；不静默替换。旧连接缺少 role 时沿用 LLM；旧 SLM 能力槽继续允许选择原先的 LLM 连接，兼容既有绑定。保存、取消和离开保护沿用当前会话机制。

Embedding / Rerank 服务入口提供两套独立方案：向量嵌入使用 embedding 协议与维度参数；重排序使用 rerank 协议，不携带向量维度。后者为 TinyBot 本轮补充的配置方案，不作为上游项目已经实现该方案的证据。

验收：模型设置分类和来源可组合筛选；按分类进入匹配配置，保存后在相同分类内显示；知识库 ASR / Embedding / LLM / VLLM 只选择已配置的相应连接；高级设置中无“添加模型连接”；三端查看分类与选择器；类型、测试和构建通过。语音音色目录及解析服务引擎目录仍是资源目录，不能视为已配置的模型连接。当前仅前端，不调用服务验证真实能力。
