# WeKnora 设置能力整合

本次为 TinyBot Web 既有前端的增量实现，沿用 React + antd、流式布局及三端外壳。参考 WeKnora `cbdcebab` 的设置、默认配置、记忆、Ollama 与集成页面。范围为本地交互，不连接真实模型、记忆提取、模型下载或 API/MCP 服务。

| 原能力 | TinyBot 归属与验收 |
|---|---|
| 常规主题设置 | 系统主题创建/编辑支持颜色模式、界面网页字体、独立等宽代码字体、字号、实时预览与重置；旧主题字段兼容 |
| 用户信息 | 头像菜单进入个人主页，编辑资料与系统用户共享成员数据 |
| 我的记忆 | 角色独立记忆六种状态，添加、导入预览、去重整理、归档与清空仅作用于当前角色 |
| 空间信息 | 资源空间显示标识、描述、文件用量、配额与存储，不建立平行空间模型 |
| 成员管理 | 继续使用系统用户、系统角色与已有授权流程 |
| 默认配置 | 模型下集中选择已配连接；新智能体、新知识库采用默认值；既有明确引用不被重写，失效引用提示 |
| 消息管理 | 智能体对话记录按角色筛选、导出与删除，和长期记忆分开 |
| 长期记忆 | 人物面板保存独立启用、写入模式、提取模型、语义召回模型、时序及容量规则 |
| 模型测试 | 每个已配模型右侧可进入分类测试，显示本地请求与模拟结果，不更新真实可用状态 |
| Ollama | 模型→本地模型→Ollama，复用中央模型连接，管理本地下载任务演示 |
| API 集成 | 模型网关→模型 API，配置协议、范围、启停及访问令牌演示 |
| MCP Server | 知识库→MCP 服务，选择允许暴露的知识库与只读工具，生成客户端配置；区别于智能体外连 MCP |
| CLI | 系统→CLI，提供配置与命令示例，不执行命令，不宣称已发布客户端 |

数据约束：主题和机器人形象存储保持独立；新增字段均可选或有默认值；不迁移或清空已有配置。除已有主题存储外，本轮配置保留在当前前端会话，刷新持久化与真实服务属于后续接入范围。

验收：Desktop 1280×1024、Tablet 768×1024、Mobile 390×884 检查上述入口、表单与底栏；纯函数测试覆盖默认引用、分类校验、记忆导入/归档/整理隔离及代码字体兼容。

## 源码参考与本次实现

参考仓库保持不修改：`frontend/src/views/settings/DefaultSettings.vue`、`OllamaSettings.vue`、`frontend/src/components/ModelEditorDialog.vue`、`frontend/src/views/integrations/{ApiIntegrationSettings,McpServerIntegrationSettings,CliIntegrationLanding}.vue`，以及 `frontend/src/locales/zh-CN.ts` 中记忆状态和策略文案。按业务归属重新实现 React/antd 交互，没有复制另一套设置中心。

- 模型属性复用既有 `config.parameters.maxTokens`，新增说明、上下文窗口、Embedding 维度和工具能力声明，不建立第二份最大输出参数。
- 默认语音连接可与已收录音色目录匹配；未收录或不匹配会提示，不能据此声称可用。Rerank 默认值用于新建知识库的检索设置。
- 六种记忆状态在试聊读取时生效：旧记录按生效中兼容，只有生效条目进入当前角色上下文。整理仅做同成员同文本去重，自动提取、语义召回未接真实服务。
- 个人资料与系统用户共享成员 ID，系统用户编辑保留头像和简介。系统角色/权限仍沿用原功能。
- 浏览器三种尺寸验证是响应式界面证据，不代替 Desktop 原生程序、Android/iPad 真机验收。

验证结果见 [三端验证](../evidence/weknora-settings-2.18/README.md)：319 项测试、类型检查与构建通过；新增页面完成 30 次三端路由检查，并验证关键配置流程。
