# 首次使用引导与配置清单

2026-11-12。本次前端增量的交互约定；延续 Console 设计，不初始化新的规格体系。

## 范围

三层引导共用现有路由和本地业务状态：首次导览、工作台配置清单、页面内提示。顺序为模型 → 知识库 → 智能体 → 机器人试聊 → 发布 → 绑定设备。基于 antd Tour，保持霁蓝、流式布局、16px 外框及现有紧凑控件。没有任何真实模型、WeKnora、设备或服务调用。

## 行为与验收

- 首次工作台展示简短导览，支持跳过、关闭后继续、完成后重看。导览结束不代表业务配置完成；独立预览 iframe 不自动弹导览。
- 配置清单只统计本次明确选择的资源，不因示例数据存在自动标记成功。用户可选择已有资源或去原页面新建；引导不自动改写资源。
- 模型要求选中的 LLM 启用且状态为“演示可用”；待检测、停用不通过。新连接保存后通过页面引导的“本地检测演练”校验原有厂商字段，或自定义提供方的字段定义；模拟鉴权失败、连接中断时仍阻止继续，重试成功才推进。该状态明确是模拟响应，不能代替真实密钥和模型服务检测。
- 知识库要求存在且至少有一份非空、已索引文本。未解析、处理中、失败都不通过。可明确跳过知识，以普通文本试聊起步；检索模式仍是本地演练。
- 智能体必须保存名称、Prompt，引用清单中的模型与知识库，并通过原有资源检查。语音、视觉、插件、MCP 和技能按实际所选能力校验，不为首次使用强制装配全部能力。
- 试聊必须使用当前智能体配置及资源完成一轮；中断、停止、失败不生成资格。独立调试页支持本次引导所选草稿，沿用原本嵌入式模拟器与当前配置凭证。
- 发布要求当前调试凭证与已发布快照匹配；初始示例的 published 标记不等于本次发布。绑定要求所选设备实际引用该已发布智能体；关联不等于在线。设备可稍后绑定。
- 跳过不计入已完成；重新继续会重新检查依赖。模型停用、知识失效、Prompt 修改等必须使下游状态失效。阻塞时指向缺失步骤，不自动跨越发布门禁。
- 引导偏好和选中 ID 仅保存到独立 `tinybot:onboarding:v1`，不存密钥，不复制业务配置。业务仍沿用当前会话存储，刷新后按重新加载的业务状态计算；不恢复不存在的数据为“成功”。存储被禁用时仍可在内存继续并提示。
- 页面提示支持单独收起和恢复；导航保留原有未保存确认。引导不自动提交表单、开始采集、播放声音或绑定设备。
- Desktop 1280×1024、Tablet 768×1024、Mobile 390×884 验证导览、跳过继续、资源关联、试聊发布绑定及失败恢复；覆盖抽屉底部可见和横向溢出，核对既有主题/形象存储未变。

## 状态与边界

已完成仅指本地配置或模拟演练。不能显示为真实服务就绪。首次导览状态、当前步骤、跳过和收起偏好可以跨刷新保留；业务数据和测试凭证仍是原有会话状态，不新增业务持久化。

## 验证记录

新增 8 项状态测试，连同原有回归共 271 项通过，类型检查与构建通过。三种视口已分别走通创建、关联、试聊、发布与绑定；知识处理失败重试、试聊中断、导览暂停继续及模型演练失败恢复另行核对。详见 [截图与验收记录](../evidence/onboarding-2.09/README.md)。这些是浏览器交互与本地模拟证据，不是原生设备或真实服务验收。
