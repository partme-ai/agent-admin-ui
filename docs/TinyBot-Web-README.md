## 2.00 浏览器头像与首屏字库

普通浏览器入口默认使用Web宿主，账号头像在右上角；屏幕宽度只决定排版，不再把宽屏浏览器当作Desktop或把平板浏览器当作iPad原生端。显式host=desktop/android/ipad的预览继续保留原账号位置。先前带host=desktop的链接会按原生桌面预览把账号放到左下，并非头像数据丢失。

网页字库使用swap，阿里普惠体常规/半粗两份本地文件合计约10MiB；首屏曾先显示替代字体再换成网页字体，视觉字面大小会改变。现在只在首次加载时等主题布局、实际用到的字库与最终布局完成，再显示页面，等待时显示小型加载环。页面内导航、主题切换及已存配置格式不变，不改字体文件。

247项测试、类型检查、构建通过。外部Chrome中按1280×1024、768×1024、390×884分别采样可见后30帧，网页字体已加载，标题尺寸均保持一个值；头像在视口内，localStorage前后逐项一致。另检查Desktop/iPad原生预览仍使用侧栏账号入口。见[验证记录](evidence/account-font-2.00/README.md)。

## 明确边界

- 所有业务数据是本地夹具或本次浏览器会话中的修改，刷新恢复初始数据；不是持久数据库。
- 模型配置是模板示例，不包含模型、额度、凭据或可用性承诺。密钥字段只演示输入样式，不保存、不发送。
- 机器人试聊使用按智能体与问题选择的本地回复夹具，不执行模型请求。文档切片按固定长度、检索按文本字符匹配；没有真实 Embedding、Rerank、PDF/OCR 或 LLM。
- 音色库可播放已下载的 MiniMax 和即梦 SeedAudio 1.0 官方固定试听片段；本机系统声音仅在单独选择本机模型并开启后输出。任意回复的云端 TTS、克隆、声纹、通讯和媒体任务仍未接入真实服务，本轮Recorder麦克风采集只在本机处理，不上传音频。升级、控制与发现不会访问真实设备。
- 版本历史/恢复已具备前端交互；版本并发与冲突合并、路由离开草稿保护、生产鉴权、持久化、国际化、真实资源策略与后端接口仍按正式任务实施。本轮没有把 110 个合同动作或 P0/P1/P2 工程任务标为生产完成。
- 独立 Server 不依赖 Tauri；Desktop / Android Tablet / iPad 原生能力随应用编译；业务定义可动态组合已有能力。Android/iPad 以受系统约束的前台运行为基线，iPad 不预设通用 USB 串口。
- 手机尺寸是响应式 Web 预览，不替代既有 Swift / Kotlin / ArkTS 原生 Mobile 路线。没有生成 Tauri、Android、iPad 或 Mobile 安装包。

预览服务器设置 `connect-src 'none'`，并排页仅通过同源且校验来源的 `postMessage` 传递页面与主题。浏览器不对外发送模型、网络配置信息或文档。
